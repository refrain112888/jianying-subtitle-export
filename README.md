# 剪映字幕导出（jianying-subtitle-export）

从**剪映专业版加密草稿**里直接提取文本/字幕，导出为标准 SRT。

剪映从 6.0 起把 `draft_content.json` 加密了，官方「字幕导出」只认智能字幕轨道，**手敲的文本导不出来**。这个小工具绕开界面，直接从草稿文件里把文字连时间码一起取出来。

- 只读，**不修改、不写回**剪映草稿
- 支持批量：一次导出全部草稿
- 中文路径、任意用户名都能用，路径不写死

## 适用版本

剪映专业版 Windows **11.x**（在 11.7.0.14652 上验证通过）。

剪映每次大版本升级都可能改加密方式。升级后如果脚本报「解密失败」，说明切片位置变了，需要重新对位，欢迎提 issue。

## 原理

草稿密文不是「整体 AES」那么简单，它的密钥材料就藏在自己身体里：

1. 文件是一段 base64 文本。在固定的 12 个字符位置（`0, 7, 20, 33, 40, 47, 59, 66, 76, 89, 99, 127`）各取 4 个字符，拼成 48 字节：
   - 前 32 字节 → AES-256 密钥
   - 后 16 字节 → GCM IV
2. 把这 12 段从原文剔掉，剩下的 base64 解码得到密文。
3. AES-256-GCM 解密，得到明文 JSON。
4. 从 `materials.texts` 取文本、从 `tracks` 的 text 轨道取 `target_timerange`，拼成 SRT。

自校验：59732 字符 → 剔除 48 → 59684 → base64 解码 44763 字节 → 解出 44747 字节 JSON。

不加载剪映的任何 DLL，不联网，不依赖账号。

## 安装

需要 Python 3.9+ 和 `cryptography`：

```bash
pip install cryptography
```

> Windows 上如果 `python` 指向微软商店的占位程序，请在「设置 → 应用执行别名」里关掉，或改用 `py -3`。

## 使用

把 `jy_subtitle_extract.py` 和 `run.bat` 放在**同一个文件夹**。

双击 `run.bat`，或者：

```bash
python jy_subtitle_extract.py
```

脚本会自动定位草稿根目录并列出所有草稿：

```
草稿目录：C:\Users\<你>\AppData\Local\JianyingPro\User Data\Projects\com.lveditor.draft
共 3 个草稿

   1)  大眼睛       2026-11-02 00:18
   2)  宣传片       2026-10-20 13:05
   3)  未命名       2026-09-11 09:42

输入序号回车导出，可连续导出多个；0 = 全部；o 打开文件夹；q 退出

序号:
```

| 输入 | 作用 |
|---|---|
| `1` ~ `N` | 导出对应草稿，可连续输入多个 |
| `0` | 导出全部草稿 |
| `o` | 用资源管理器打开草稿目录 |
| `q` | 退出 |

也支持直接指定目录，跳过菜单：

```bash
python jy_subtitle_extract.py "D:\某个草稿目录"
python jy_subtitle_extract.py "D:\某个草稿目录" "D:\输出.srt"
```

## 输出

默认写到**脚本所在文件夹**，文件名 = 草稿文件夹名：

```
大眼睛.srt
```

格式为标准 SRT（UTF-8 with BOM + CRLF），剪映、PR、DaVinci、PotPlayer 都能直接读。

## 草稿目录怎么找

优先级：

1. 环境变量 `JIANYING_DRAFT_ROOT`（自定义位置时用）
2. `%LOCALAPPDATA%\JianyingPro\User Data\Projects\com.lveditor.draft`

用户名不写死，换电脑照样能跑。

列表里会跳过 `.` 开头的系统目录（`.recycle_bin`、`.cloud_cache_*`），只显示真正含 `draft_content.json` 的文件夹。

## 常见问题

**导出 0 条字幕？**
这个草稿里没有文字轨道。工具只提取文本，不识别语音；要语音转字幕请在剪映里用「智能字幕」。

**解密失败？**
剪映版本变了。开 issue 附上剪映版本号。

**能写回草稿吗？**
不能，也不打算做。本工具是单向只读。
